# memclean

Умный фоновый очищатор ОЗУ для слабых Windows-ПК (4 ГБ и меньше). Один exe ~300 КБ, в фоне ~2 МБ RAM.

Не чистит всё по таймеру (это только вызывает подкачку), а при реальной нехватке памяти выдавливает
рабочие наборы **простаивающих** фоновых процессов, чтобы активной программе досталось больше RAM.

- гистерезис: старт на 82% загрузки, стоп на 72%;
- трогает только процессы, которые не едят CPU;
- не трогает активное окно, недавние окна (alt-tab), системные процессы, проводник, меню Пуск, звук;
- если процесс быстро вернул память — кулдаун для него удваивается (до x16), без пинг-понга с подкачкой;
- когда пользователь отошёл — работает агрессивнее, с админом ещё и дедуплицирует страницы памяти;
- лимит 400 МБ за проход, чтобы не перегружать диск;
- сам работает на idle-приоритете в фоновом режиме.

## Сборка

```
cargo build --release
```

## Использование

| Команда | Что делает |
|---|---|
| `memclean.exe --install` | копирует в `%LOCALAPPDATA%\memclean`, включает автозапуск и запускает. От админа — через планировщик задач с повышенными правами, иначе через `HKCU\Run` |
| `memclean.exe --status` | состояние памяти и хвост лога |
| `memclean.exe --once` | один агрессивный проход с выводом в консоль |
| `memclean.exe --uninstall` | убрать автозапуск и остановить |
| `memclean.exe` | фоновый режим без окна |

Настройки — `memclean.ini` рядом с exe (создаётся при первом запуске): пороги, кулдауны, исключения
(`exclude=obs64.exe,discord.exe`). Лог — `memclean.log` там же.
